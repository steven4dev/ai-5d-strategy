# AI-5D 策略分析 V3.0 雙通道大師版

台股技術分析工具，單一 HTML 檔案，免安裝，開箱即用。

**線上版本 →** [steven4dev.github.io/ai-5d-strategy](https://steven4dev.github.io/ai-5d-strategy/)

---

## 功能概覽

### 圖表指標（由上至下）
| 面板 | 內容 |
|------|------|
| 價格 | K 線圖、VWAP、均價、22MA、60MA、240MA、天花板／地板 |
| 通道 | 布林通道（BB）或肯特納通道（KC），可即時切換 |
| 成交量 | 量柱（紅漲綠跌） |
| KD | 隨機指標（9,3,3），標示 20 / 80 超賣超買區 |
| MACD | DIF、MACD 線、OSC 柱 |
| RSI | 14 期 RSI，標示 30 / 70 參考線 |
| VIX | CBOE 恐慌指數 |
| 油價 | WTI 原油價格 |

### 策略訊號
| 符號 | 意義 |
|------|------|
| 💎 | 大師抄底（長線防禦底部） |
| 🚀 | 強勢突破 |
| ▲ | 觸底買進（反彈） |
| ▼ | 逢高減碼 |
| ✖ | 嚴格停損 |
| ■ | 波動壓縮待爆（TTM Squeeze） |

### 通道狀態分類
- **A（震盪）**：帶狀橫走，等待方向
- **B（壓縮）**：通道收縮，蓄積能量
- **C（多頭）**：價格在中軌上方擴張
- **D（空頭）**：價格在中軌下方擴張

### 其他功能
- **三大法人**：外資、投信、自營商每日買賣超
- **財報面板**：EPS、本益比、TTM 數據
- **新聞面板**：個股相關新聞
- **自選清單**：收藏常用標的，快速切換
- **詢問價格**：輸入目標價，即時顯示策略建議
- **資金水位**：試單 10–30%、輕倉 20%、半倉 50%、減碼、空手

## 使用方式

### 方法一：線上直接使用
前往 [steven4dev.github.io/ai-5d-strategy](https://steven4dev.github.io/ai-5d-strategy/)，輸入台股代碼即可。

### 方法二：本機執行
1. 下載此 repo（或 clone）
2. 雙擊 `啟動伺服器.bat`
3. 瀏覽器自動開啟 `http://localhost:8000/AI-5D.html`

> 需要 Python 3.x（Windows 內建或自行安裝）

---

## 操作說明

| 動作 | 效果 |
|------|------|
| 點擊圖表任一日期 | 鎖定該日，底部顯示 OHLC、法人、各指標細節 |
| 左右箭頭（或懸浮面板） | 在鎖定日期間前後導航 |
| 切換 BB / KC | 即時切換布林通道或肯特納通道 |
| 調整天數 | 15 / 30 / 45 / 60 / 120 / 240 交易日 |
| 輸入詢問價格 | 顯示該價位的策略建議與資金水位 |

## 技術架構

- **前端**：純 HTML + Vanilla JavaScript（單檔，無需建置）
- **圖表**：[Plotly.js](https://plotly.com/javascript/) 2.32
- **樣式**：Tailwind CSS（CDN）
- **圖示**：Font Awesome 6
- **資料來源**：[FinMind](https://finmindtrade.com/) 開放 API（台股股價、法人、財報、VIX、油價）
